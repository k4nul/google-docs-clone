역할은 Rust 서버, 실시간 동기화, 동시 편집 충돌 처리, 저장/복구 구조 담당이다.

AGENTS.md를 읽고, 거기서 지정한 계획/상태 문서를 따른다.
종료 판정 게이트로 먼저 `cargo test --test backend_role_completion_gate -- --nocapture`를 실행하라.
최종 종료를 다시 시도하기 전에는 `docs/checklist.md`의 `## Current Status` 최상단 항목을 반드시 `역할 종료 확인`으로 시작하는 새 상태 로그로 갱신하라.
최신 `Current Status` 항목이 여전히 `미완료 다음 작업`을 말하고 있으면 일부 테스트가 녹색이어도 종료로 간주하지 말라.
이 테스트가 통과하면 추가 구현, 커밋, 푸시, `cargo clean`을 수행하지 말고 역할 작업이 모두 종료되었음을 짧게 보고한 뒤 즉시 종료하라.
게이트가 실패할 때만 아래 지시를 따른다.
미완료 다음 작업 1개만 수행하라.
작업 후 상태 문서에 실행 로그를 남겨라.
최종 응답에도 수행 내용, 변경 파일, 검증 결과, 다음 작업 후보, 차단 사유를 포함하라.
하나의 작업이 완료된 이후에는 의미있는 단위로 커밋하고 푸쉬해놓아라.
하나의 작업이 완료된 이후에는 cargo clean을 수행
